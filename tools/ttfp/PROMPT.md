# Завдання: переклад українською (Typst)

Ти перекладаєш українською мовою підручник Rob Nederpelt & Herman Geuvers,
*Type Theory and Formal Proof: An Introduction* (CUP, 2014), який тут
набирається в Typst.

## Що на вході

* Текст оригіналу, витягнутий з PDF (`pdftotext -layout`): шляхи вказані
  в завданні. Формули, таблиці та дерева виведень у ньому розсипаються на
  рядки — відновлюй їх за змістом і за правилами Typst.
* Файл-каркас розділу (`src/chapters/...typ` або `src/appendices/...typ`) з
  уже перекладеними заголовками підрозділів і маркерами `#todo-section`.
* `GLOSSARY.md` — обов'язковий глосарій термінів (англ. → укр.).
* `book.typ` — спільний шаблон: нумеровані середовища тверджень і скорочення
  для λ-систем.

## Що треба зробити

Створити файл `tools/ttfp/out/<chapter>/part<N>.typ` — Typst-код рівно тих
підрозділів, які вказані в завданні.

Правила:

1. Кожен підрозділ починається з заголовка рівня 2 **точно таким текстом, як
   у каркасі** (включно з `#lto`, `#ltwo`, `#lomega`, `#lp`, `#lc`, `#ld0`,
   `#ld`, `#sym.or`), у тому ж порядку, що й у завданні.
2. Кожне нумероване твердження оригіналу (Definition, Theorem, Lemma,
   Corollary, Proposition, Example, Remark, Notation, Convention, Exercise,
   Axiom) оформлюй відповідним середовищем з `book.typ` — і **ніколи не
   вписуй номер вручну**:

   ```typst
   #definition(name: "Редекс")[ ... ]
   #theorem[ ... ]
   #lemma[...]
   #corollary[...]
   #proposition[...]
   #example[...]
   #remark[...]
   #notation-item[...]
   #convention[...]
   #exercise[...]
   #proof[ ... ]   // доведення, завершується квадратиком
   ```

   Нумерацію (вигляд «Означення 3.4») середовища роблять самі. Оригінальні
   номери треба зберегти лише в **посиланнях** у тексті: «див. означення
   1.2.1», «за теоремою 1.9.8», «(див. вправу 1.10)».
   Назву в `name:` став тоді й лише тоді, коли в оригіналі після номера є
   назва в дужках, напр. `Definition 1.3.2 (The set Λ of all λ-terms)` →
   `#definition(name: "Множина Λ усіх λ-термів")[...]`.
3. Доведення оформлюй `#proof[...]`; пункти — `#enum` / `#list` або абзацами,
   як в оригіналі; підпункти (a), (b) зберігай.
4. Математика — у математичному режимі Typst. Перевірені позначення (Typst
   0.15), використовуй саме їх:

   | що | Typst |
   |---|---|
   | ⊢ (turnstile) | `$Gamma tack.r M : sigma$` |
   | ∗ (сорт) | `$ast$` |
   | □ (сорт) | `$square$` |
   | λ-системи | `#lto` `#ltwo` `#lomega` `#lp` `#lc` `#ld0` `#ld` (і в тексті, і в формулах) |
   | →β (один крок) | `$arrow.r_beta$` |
   | ⟶β (багато кроків) | `$arrow.r.long_beta$` |
   | =β (конверсія) | `$=_(beta)$` |
   | ↦ | `$arrow.r.bar$` |
   | ⊥ ¬ ∧ ∨ ∀ ∃ ∈ ∅ ⊆ ≤ ≥ | `$bot$ $not$ $and$ $or$ $forall$ $exists$ $in$ $emptyset$ $subset.eq$ $lt.eq$ $gt.eq$` |
   | ∉ (не належить) | `$x in.not Gamma$` |
   | ≠ (не дорівнює) | `$x eq.not y$` |
   | ≢ (не тотожне) | `$M equiv.not N$` |
   | ℕ ℤ ℚ ℝ | `$NN$ $ZZ$ $QQ$ $RR$` |
   | ≡ | `$equiv$` |
   | дужки, що масштабуються | `$lr(])$`, `$lr([)$` |

   **Увага, пастка з ∧/∈/≠:** витяг із PDF (навіть виправлений) подекуди міг
   містити **додатне** відношення там, де книжка друкує заперечення. Завжди
   перевіряй за змістом: у правилі (var) та (weak) умова — «$x in.not Gamma$»
   (змінна є новою), у правилах (def)/(def-prim)/(par) — «$a in.not Delta$»,
   в означеннях підстановки та альфа-конверсії — «$y in.not F V (M)$». Якщо
   пишеш `in` або `eq` там, де мало бути ∉ / ≠, твердження стає **хибним** —
   це найгрубіша можлива помилка перекладу.

   Мітку виведення пиши як `$Gamma tack.r M : sigma$`. Українські слова в
   формулах (напр. «якщо») — звичайним текстом поза формулою.
5. Дисплеї з номерами формул: у оригіналі їх майже немає; якщо є — постав
   лейбл `$ ... $ <eq:name>` і посилайся `@eq:name`. Без номерів у оригіналі
   нічого не нумеруй.
6. Зображення/таблиці відтворюй як `#table` або `#figure` з підписом;
   підписи перекладай («Рисунок 1.1 Дерево (y (λx . (x z)))»). Дерева
   виведень — `#table` або стовпчикові формули з горизонтальною рискою;
   головне, щоб читалося як в оригіналі.
7. Зберігай **усе**: приклади, зауваження, вправи, виноски, посилання на
   літературу («(Church, 1933)»), імена авторів, назви книг (латиницею),
   програмні ідентифікатори (Automath, Coq, Mizar, nat, list), URL.
8. Термінологію бери з `GLOSSARY.md`; якщо потрібного терміна немає — вибери
   усталений український і додай рядок у `GLOSSARY.md` (окремим невеликим
   редагуванням), щоб переклад був однаковий у всіх розділах.
9. Жодних маркерів `#todo-section`, жодних «TODO», жодних квадратних дужок
   з англійським текстом у результаті. Перекладай усе, нічого не скорочуй і
   не переказуй: це повний переклад, а не конспект.
10. У вихідному файлі `part<N>.typ` **немає** ні заголовка рівня 1, ні
    `#import "/book.typ": *`, ні коментаря-шапки — лише підрозділи рівня 2.
11. Не чіпай інші файли репозиторію, крім `tools/ttfp/out/**` та (за потреби)
    одного-двох рядків у `GLOSSARY.md`.

## Обов'язкова перевірка перед відповіддю

Файл має компілюватися Typst 0.15:

```sh
cd /Users/ihor/ttfp
typst compile --root . tools/ttfp/out/<chapter>/part<N>.typ /tmp/check-<chapter>-<N>.pdf
```

Виправляй помилки, доки компіляція не пройде (файл з самими підрозділами без
шаблону компілюється сам по собі — це нормально, що нумерація тверджень у
такому PDF умовна).

Наприкінці відповідай одним коротким абзацом: які підрозділи перекладено,
скільки тверджень кожного виду, чи компілюється файл. Ніякого переказу
змісту.
